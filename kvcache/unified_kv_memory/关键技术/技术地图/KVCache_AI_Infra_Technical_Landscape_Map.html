KVCache 职责认知的三次代际跃迁 (Paradigm Shift)

Phase 1 (2022-2023): 单卡显存临时暂存区

【系统角色】单算子计算的临时中间张量，生命周期局限于单次推理请求，随批次结束即释放。

【核心焦点】以 vLLM PagedAttention 为代表，重点解决单卡显存碎片化与显存容量墙；基础设施无感知。

Phase 2 (2024-2025): 分离式网络传输载荷

【系统角色】Prefill 与 Decode (PD) 分离架构下的分布式通信消息载荷，跨节点数据流主角。

【核心焦点】基于 RDMA/TCP 的流式推拉 (Mooncake, LMCache)；Host DDR 频繁换入换出引发 Incast 与总线拥塞。

Phase 3 (2026 前沿): 共享状态织物与调度核心

【系统角色】驱动集群互联拓扑、存储分层、总线流量仲裁与计算放置决策的第一等公民资源。

【核心焦点】计算存储双向感知、非对称总线借调、微架构 SMEM 零拷贝、无锁只读解耦与硬件硬 QoS 隔离。

六大核心技术领域与关键解决手段

【领域一】 微体系结构访存阻抗与零拷贝陷阱

算子微架构层
核心矛盾：GPU SM 极速访存 (TB/s) 与慢速总线 (GB/s) 存在巨大物理鸿沟
【底层根因】API 层朴素零拷贝解引用 Host 内存致 L2 缓存被击穿 (命中率 77%→32%)，重复搬运数十 GB 冗余流量使延时暴增 20 倍；PagedAttention 细粒度小页撕裂总线 (有效利用率仅 5%~22%)；CPU 解释型分配器打断 CUDA Graph。
• CPU 内存感知片上分块 (SMEM Tiling)：
将 Host 慢速 KV 单次拉入 GPU SM 片上共享内存常驻，片上遍历本地 Query 与权重，总线重复搬运量削减 98.8%，L2 命中率恢复至 75.1%。
• 计算与传输布局解耦 (Decoupled Layout)：
显存侧采用 Layer-First 迎合注意力核函数局部性，外存侧采用 Page-First 连续大块打满总线物理带宽，突破小页总线饥饿 (有效带宽达 48 GB/s)。
• GPU 协助细粒度并发转置 (GPU-Assisted I/O)：
启动专用轻量 GPU 线程块，在流式搬运中以 128B 细粒度在线完成地址映射与布局转置，前台在线计算干扰低于 5%。
• 图内并行缓存管理 (In-Graph Cache Manager)：
将块映射表与分配状态全量下沉 GPU HBM，由 CUDA Graph 原生算子并行分配释放，消除 CPU 解释器打断，时延降低 1.6~1.9x。

【领域二】 非对称拓扑拥塞与跨域闲置带宽汇聚

总线与网络拓扑层
核心矛盾：局部通信链路过载饱和 vs 全局高速拓扑大面积闲置
【底层根因】多轮长文本下历史 KV 命中率超 98%，传统 PD 分离仅允许 Prefill 节点读存储致其存储网卡 100% 满载，而 Decode 存储网卡常态闲置；单机内 GPU 私有 PCIe 链路所有权刚性 (利用率不足 27%)，局部打满时无法借用邻居空闲链路。
• 双路径回源与中继转运 (Dual-Path Retrieval)：
打破仅 PE 读存储假设，允许 Decode 节点利用空闲存储网卡回源历史 KV，再借助内部充裕的高速计算网络转运给 Prefill 节点，消除单侧过载。
• 跨卡 Scale-Up 总线池化 (Scale-Up PCIe Pooling)：
单机内 GPU 借助跨卡高速互连 (NVLink) 中继借用邻居 GPU 的空闲 PCIe 链路访问 Host 内存，将私有链路汇聚为整机共享带宽池。
• 固定块双向流水中继 (Fixed-Block Pipelining)：
将跨卡跨总线传输切分为 16MB 固定块双向流水，中继跳延迟完全被 PCIe 传输时间掩盖，固定显存占用仅需数十 MB。
• 组级意图暴露与单份回源广播 (Grouped I/O Broadcast)：
应用显式声明协同读写批次；多节点相同数据仅由单源从存储回源一次，随后在高速计算网络内流水串行广播分发，KVCache 冷读 TTFT 降低 23%。

【领域三】 跨节点内存池化的一致性税与同步放大

分布式内存一致性层
核心矛盾：海量分布式缓存复用 vs 控制面元数据流量吞噬有效载荷
【底层根因】解耦内存池跨机延迟高数十倍；传统缓存淘汰机制维持热度与双向链表吞噬 86.6% 网络带宽 (正文仅占 13.4%)，并发原子 CAS 压制读吞吐 4.3x；硬件一致性区域 (SCR) 受限于物理面积仅数十 MB，元数据换出引发级联雪崩。
• 只读不可变数据与元数据本地化 (Share Data, Not Metadata)：
共享池中仅存放不可变只读 KV 正文，目录索引与状态在本地闭环，从物理上杜绝并发写冲突，消除 95% 以上的总线探测一致性税。
• 组级生命周期管理解耦 (Group-Level Housekeeping)：
正文访问保持单对象细粒度直达，淘汰、状态刷新与回收按组 (如 64 个) 批量执行，将控制面管理复杂度降低两个数量级。
• 本地热度累计与批量原子回刷 (Local Counting & Batched Flush)：
命中仅本地累加计数，跨机同步时单次 8B 原子指令打包连续多个对象计数批量回刷，发射频率降低 8 倍。
• 分裂式元数据与共享追加日志 (Split Metadata & Append-Only Log)：
硬件受限一致性区仅存放极简原子锁，庞大目录树移至大容量非一致性内存，通过顺序追加日志异步推进，元数据换出开销削减 8 倍。

【领域四】 端到端内存语义直达与控制面解构

互联通信与内存语义层
核心矛盾：高频细粒度存取需求 vs 繁重网络协议栈握手开销
【底层根因】KVCache 呈跨层跨头离散分布，高频细粒度 Gather/Scatter 成为常态；RDMA 依然保留网络协议语义，描述符准备、完成队列轮询与流同步吃掉 75% 操作时间；交换式内存网络缺乏端侧流控，突发大吞吐霸占端口引发队头阻塞与饥饿。
• 全局统一内存编址与直通映射 (Global DAX Memory Mapping)：
利用内存交换网络将机架内共享内存映射为全局统一虚拟地址空间，计算核函数通过直接解引用直达访问，16KB 访问从网络级 10µs 降至纳秒/微秒级。
• 发起者角色判定软件一致性 (Initiator-Based Software Coherence)：
按读写发起者角色在软件层精准下发轻量 Cache Flush/Invalidate 指令，消除昂贵的硬件全局侦听探测总线税。
• 细粒度设备级重排核函数 (Fine-Grained Gather/Scatter Kernels)：
在设备端原生实现离散页表到连续共享内存块的线速聚集写入与发散读取，配合多内存通道交错存取打满物理吞吐。
• 核心无状态端侧流控传输 (Core-Stateless End-Host Transport)：
在不可编程交换机前端，通过读取 CPU 性能计数器反推真实内存流量需求，将路径瓶颈反向映射为线程时间配额，根除队头阻塞。

【领域五】 计算—存储跨层双向感知与状态预测

运行时感知与编排层
核心矛盾：上层动态时序交互语义 vs 下层存储黑盒盲目调度决策
【底层根因】存储层缺乏模型回答长度与用户交互感知，通用 LRU/LFU 错误驱逐高潜力历史 KV；计算调度看不见 KV 所在介质层级 (DRAM vs SSD)，慢速 SSD 请求占死队头引发响应恶化 3.8x；无前置预测信号导致多 GB 搬运硬生生落入 TTFT 关键路径。
• 计算—存储双向感知提示接口 (Bidirectional Awareness Interface)：
存储层向上暴露 KV 所在介质层级与字节规模；计算引擎向下输出模型回答长度，为下层淘汰决策提供未来重用距离关键线索。
• 层级解耦双队列与响应比优先调度 (Split Queues & disk-HRRN)：
将请求拆分为可执行队列与准备队列，慢速 SSD 读取按响应比动态升权调度，消除慢 I/O 对快速内存命中的队头阻塞，排队时延骤降 57.5%。
• 基于回答长度的命中潜力淘汰 (Answer-Length Guided Eviction)：
依据上一轮模型回答长度估算用户下一次交互的重用距离下界，优先保留更快被再次复用的历史张量，缓存未命中率降低 57%~70%。
• 建议请求弱信号提前预取 (Advisory Requests & Predictive Prefetch)：
捕获用户输入、打字或 Agent 调用图等前置弱信号，在真实请求到达前 5~11 秒提前触发迁移预取，彻底将多 GB 状态搬运剥离 TTFT 关键路径。

【领域六】 多维代价感知动态选路与混压 QoS 隔离

自适应流控层
核心矛盾：静态配置无法适应动态波动 vs 前后台混压长尾抖动失控
【底层根因】网络有效带宽时刻剧烈波动，静态固定压缩在带宽充裕时编解码耗时反噬传输收益，引发高达 0.9s 时延毛刺；软件内存遥测滞后数百毫秒且消耗 20% CPU 算力；后台满载换出瞬间抢占内存控制器与网络队列，在线推理 TPOT 尾部延迟断崖式恶化。
• 模块化压缩空间与约束 Pareto 画像 (Modular Pareto Profiling)：
将压缩解构为变换、量化、编码三级流水，离线通过约束贝叶斯优化快速构建准确率、压缩比与耗时三维最优候选集。
• 带宽阈值下包络常数时间选路 (Lower-Envelope O(1) Path Selection)：
基于实时链路有效带宽，沿多配置延时直线的下包络在常数时间内判定最优加载/压缩/重算路径，消除性能倒挂，PD 分离下加速达 9.13x。
• 硬件级物理内存通道硬隔离 (Physical Memory Channel Hard Isolation)：
将低延迟在线业务与大吞吐后台搬运严格绑定至不同物理内存通道，彻底消除 99% 的总线与控制器争用，在线推理性能逼近独占。
• 硬件多优先级队列统一仲裁与协处理卸载 (Hardware Priority VL & ASIC Offload)：
在线推理通信映射高优先级硬件通道，后台大吞吐搬运映射低优先级；利用闲置 NVDEC 视频 ASIC 处理压缩流，保证在线 TPOT 零受挤占。
