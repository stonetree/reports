## 1. 实验背景与核心攻坚命题

在前期立项评审中，评审专家对“网络多打一 (N-to-1 Incast)、多卡张量并行 (TP=8) 协同传输中的性能非等比劣化”表示关注。为了在有限的硬件环境（如 2 节点物理机、单机多网卡/多端口、或单机多进程回环）下，以**严密、可复现、纯实测的数据**正面证实网络排队动力学与 Coflow 木桶短板效应，特设计本专项实验方案。

### 核心验证命题：
1. **命题一（N-to-1 Incast 非等比时延爆炸）**：当并发发送端数量从 $N=1$ 增加至 $N=2, 4, 8, 16$ 时，受端口缓冲队列（Buffer Bloat）与排队微突发影响，P99 尾部时延的恶化倍数远大于 $N$ 倍的线性增长（呈现超线性/非等比长尾激增）；
2. **命题二（TP=8 Coflow 木桶短板与偏斜放大）**：在张量并行（TP=8）场景下，计算必须等待 8 张卡的 KVCache 全部到位（$\text{CCT} = \max_{i=0..7} T_i$）。在多组并发与轻度网络扰动下，单个流的轻微抖动会被 $\max(\cdot)$ 算子显著放大，导致 CCT 恶化幅度远超单流平均时延；
3. **命题三（Layer 0 起始首层排队倒置与计算气泡）**：在无语义通用队列中，先发出的 Layer 0 数据包受微突发干扰发生到达时序倒置，导致上层 NPU GEMM 计算流水陷入气泡停顿；通过硬件 QoS 队列可彻底消除该停顿。

## 3. 实验动力学模型与数学公式

### 3.1 N-to-1 Incast 队列时延非等比膨胀模型
设瓶颈链路服务率为 $\mu$，单个流的包到达率为 $\lambda$。当 $N$ 个流并发打满时，总到达率 $\Lambda = N \cdot \lambda \to \mu$。
在有限缓冲（Buffer Size $= B$）下，排队时延分布呈现重尾（Heavy-tailed）。尾部时延 $P_{99}$ 不仅包含传输时延 $T_{\text{tx}}$，还叠加了突发排队时延 $T_{\text{queue}}$：
\[
T_{P99}(N) = T_{\text{tx}} + \frac{B}{\mu} \cdot f_{\text{burst}}(N) + T_{\text{retransmit}} \cdot P_{\text{loss}}(N)
\]
当 $N$ 超过交换机突发吸收阈值时，$P_{\text{loss}}$ 激增，触发重传，使 $T_{P99}$ 呈现数倍至数十倍的超线性激增。

### 3.2 TP=8 Coflow 完成时间 (CCT) 木桶效应模型
一个 TP=8 Coflow 包含 8 个子流 $\{f_0, f_1, \dots, f_7\}$。假设每个流的传输时间独立服从均值为 $\mu_T$、标准差为 $\sigma_T$ 的分布，则 Coflow 的端到端耗时为：
\[
\text{CCT} = \max \{ T_0, T_1, \dots, T_7 \}
\]
根据极值统计理论（Extreme Value Theory），当子流存在微小方差 $\sigma_T$ 时，$\mathbb{E}[\text{CCT}]$ 显著大于 $\mu_T$。在网络拥塞时，若多个 Coflow 的子流相互交织并被公平限速，最慢流将被进一步推后，导致全集群推理吞吐大幅受挫。
