| ---------------------------- | --: | ------------ | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------- |
| L2-KV-PublishCommit-033      |  P0 | 统一协议与标准接口    | 本需求要求 KVConnector 在 put/get/prefetch/evict 之外补充 publish_prepare、publish_commit、publish_abort 三阶段发布接口：NPU/GPU runtime 产生 KV 后先注册待发布 KV object，只有当 KV data、KVMeta、ready bitmap、checksum 和 placement record 均完成后才允许 commit；abort 时必须回滚半成品对象并释放临时 buffer。       | NPU/GPU 生成 KV 后进入统一 KV 内存池 |
| L2-KV-AttachHandle-034       |  P0 | 共享访问与故障控制    | 本需求要求 Connector 返回标准 KVAttachHandle，而不是只返回 KV 数据位置；handle 必须包含 object_id、prefix_span、rank_slice、layout_version、device_ptr 或 transfer_plan、ready_bitmap、visibility_level、lease_id、placement_id 和 release callback，使上层 attention runtime 能安全 attach 和 detach。 | 前缀命中后 KV 安全消费              |
| L2-KV-ConsumeEligibility-035 |  P0 | 本地元数据缓存与快速判定 | 本需求要求 Connector 提供 consume eligibility 查询接口：输入 prefix_hash、semantic identity、deadline、target_device、rank context，返回 CONSUMABLE、WAIT_READY、NEED_LOAD、NEED_COPY_TO_HBM、MIGRATING_RETRY、STALE_RECOMPUTE、MISS 等语义结果，避免 Scheduler 直接解释底层 KV 状态。                  | 前缀命中后的可消费状态判定              |
| L2-KV-SemanticIdentity-036   |  P1 | 统一协议与标准接口    | 本需求要求定义 KVSemanticIdentity 标准结构，至少包含 model_id、model_weight_version、tokenizer_hash、template_version、adapter_id、layout_version、dtype、position_policy、attention_policy、rank_partition、tenant_domain 和 cache_salt；Connector 在返回 hit 前必须完成 identity 兼容性过滤。       | 防止语义不兼容 KV 被误复用            |
| L2-KV-StateErrorCode-037     |  P0 | 共享访问与故障控制    | 本需求要求 Connector 层定义统一状态错误码，将 L3/L4 返回的 MIGRATING、LEASE_CONFLICT、STALE_VERSION、VISIBILITY_TIMEOUT、REPLICA_DEGRADED、CHECKSUM_FAILED、QUOTA_BLOCKED、BACKEND_BUSY 等状态转换为上层可执行的 retry、wait、load、copy、recompute、partial hit 或 miss 信号。                             | KV 状态复杂场景下的快速降级与恢复         |
| L2-KV-PartialAttachPlan-038  |  P1 | 传输描述与布局协商    | 本需求要求 Connector 支持 partial attach plan：当 prefix 只有部分 block/page 可用时，返回可 attach 的连续 prefix 区间、缺失 suffix 区间、推荐 recompute boundary、所需 block table 拼接信息与 transfer descriptor，支持“命中前缀 attach + 后缀重算”的混合执行。                                                       | 部分前缀命中复用                   |
